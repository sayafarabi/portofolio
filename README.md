## 👋🏼 Tentang Project

Portfolio pribadi modern yang dibangun dengan **React**, **Tailwind CSS**, dan **Framer Motion**. Website ini dirancang dengan tampilan futuristik, animasi halus, dan fully responsive. Cocok untuk developer yang ingin menunjukkan karya, skill, dan pengalaman secara profesional.

### ✨ Fitur Unggulan

- 🌙 **Dark mode futuristik** + efek glassmorphism
- 🧊 **Sticky navbar** dengan efek blur & active link indicator
- ⌨️ **Typing animation** otomatis
- 🌌 **Particle background** interaktif
- 🎯 **Smooth scrolling** & scroll spy
- 📊 **Animated skill bars & counter**
- 🃏 **Project filter & search** + modal detail
- 📜 **Timeline pengalaman belajar** interaktif
- 📬 **Contact form** siap integrasi (Formspree)
- 📱 **Fully responsive** (mobile-first)
- ⚡ **Lazy loading gambar** & optimasi performa
- ✨ Animasi spring, stagger, & in-view (Framer Motion)

## 🚀 Cara Menjalankan di Lokal

Ikuti langkah berikut untuk meng-clone dan menjalankan project ini di komputermu.

### Prasyarat

- [Node.js](https://nodejs.org/) (v16+)
- [Git](https://git-scm.com/)

### Instalasi

```bash
# 1. Clone repositori
git clone https://github.com/sayafarabi/portfolio.git

# 2. Masuk ke folder proyek
cd portfolio

# 3. Install dependensi
npm install

# 4. Jalankan development server
npm run dev


📁 Struktur Folder

src/
├── animations/         # Shared framer-motion variants
├── components/         # Reusable UI components (Navbar, Hero, etc.)
├── data/               # Data statis (projects, skills)
├── hooks/              # Custom React hooks (useDarkMode, useTypingEffect)
├── pages/              # Halaman utama (Home)
├── App.jsx             # Root component
├── main.jsx            # Entry point
└── index.css           # Tailwind base + custom utilities
